# Mini Code APK

Android landscape code workspace based on the supplied Mini Code interface.

## Build
GitHub Actions builds `app-debug.apk` on pushes to `main`. The APK is published as the `Mini-Code-APK` workflow artifact.

## Included
- Landscape Android WebView shell
- Local folder picker via Android Storage Access Framework
- File creation, reading, editing and saving
- HTML preview

AI agent and chat are intentionally not included in this first version.
